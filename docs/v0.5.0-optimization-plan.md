# dsh-opencode-go v0.5.0 开发优化规划文档

> **目标版本**：`v0.5.0`（跨版本综合体验与工程大升级）
> **基线版本**：`v0.4.9`
> **审视视角**：前端设计师 + 产品经理 + 真实高频用户
> **开发流程**：按阶段实施 → 单元测试与规范验证（`typecheck` / `check:hygiene` / `vitest` / `compile`）→ 按阶段提交 → 最终统一发版与打包 `dsh-opencode-go-0.5.0.tgz`

---

## 一、背景与审视总结

`dsh-opencode-go` 在 v0.4.x 阶段已具备扎实的工程底座（WCAG 1.4.11 对比度自动化断言、单一保存手势、吐字前无感容灾、DS Bot 自动高度外壳兼容等）。但在以真实用户与挑剔设计师视角全量审视前端代码、样式 Token 与界面交互后，发现项目存在多处实锤交互/状态 Bug、高频动线摩擦、主题辨识度不足、信息冗余与图表可读性瓶颈。

v0.5.0 将围绕 **6 大维度 × 3 项可落地优化（共 18 项）+ P0 实锤 Bug 修复** 进行系统性重构升级。

---

## 二、六大维度问题清单与改进方向

### 维度 1：功能完整性（Functional Completeness）
- [x] **1.1 配额月度告警、瓶颈透出与多画像估算**：
  - 输入栏胶囊在月度额度 `>= 80%` 或限流时展示月度告警标识，消除“5 小时余量充足但月度已满”的盲区；
  - 弹层剩余次数估算明确标注当前受限瓶颈窗口（`5 小时` / `每周` / `每月`）；
  - 模型详情页「满额预估请求数」支持 3 档使用画像切换（轻度问答 / 标准编码 / 长上下文 Agent）及套餐档位对比预览。
- [x] **1.2 连通性探测与添加账号体验补全**：
  - 高级设置连接区新增「测试连接」能力（通过 Host 安全探测草稿中的 Go/Free 网关与代理连通性及延迟，不泄露凭据）；
  - 添加账号表单直接内置「订阅套餐」选择器与密码显隐切换，并兼容后端原子写入套餐档位。
- [x] **1.3 Free 未开启引导态与一键脱敏诊断摘要**：
  - `freeEnabled` 关闭时，模型页「免费模型」Tab 渲染清晰引导卡与一键启用入口，不再误报“网关无可用模型”；
  - 「关于」页新增「复制诊断摘要」（纯前端拼装脱敏 Markdown 诊断信息），并将「文档」外链修正为用户指南 `docs/advanced.md`。

### 维度 2：交互易用性（Interaction Usability）
- [x] **2.1 账号管理与输入栏切号全动线重构**：
  - 账号卡片整行可点击展开/收起，支持多行同时展开对比；
  - 非首位账号提供一键「设为当前」按钮（直接调用 `selectAccount`）；
  - 独立「账号」子页（`surface="page"`）禁用外层折叠，避免误点收起整页；
  - 输入栏弹层切号列表异步拉取并展示各账号的 `5h / 周` 额度百分比与健康状态，告别盲切。
- [x] **2.2 高级设置人性化单位、单字段重置与精准校验**：
  - 毫秒/字节/像素字段实时展示人类可读换算提示（如 `≈ 5 分钟`、`20.0 MB`、`4.2 MP`）；
  - 每个字段显示默认值、自定义标识与单项重置按钮；
  - 按 `NUMERIC_FIELD_LIMITS` 与 URL 规则提供字段级精准报错说明；
  - 控制台顶部「高级设置」Tab 在存在未保存草稿时显示脏点指示器。
- [x] **2.3 模型页筛选排序、批量防呆与即时反馈**：
  - 新增「已开启 / 已关闭」筛选与排序切换（默认 / 额度倍率 / 上下文窗口 / 最新发布）；
  - 批量操作「全部开启 / 全部关闭」标明影响数量，并在操作后提供一键撤销（Undo）条；
  - 容量输入防抖保存后展示轻量 `✓ 已生效` 反馈；思考预算新增 `2K / 4K / 8K / 16K / 32K` 快捷预设芯片。

### 维度 3：设计美观性（Visual Aesthetics & Craft）
- [x] **3.1 双主题微缩 Bento 预览与胶囊网格去空洞**：
  - Native / Classic 主题预览升级为微型界面卡片（展示字体差异、强调色进度条、对比色块与胶囊样本），一眼可辨；
  - 外观页 5 种输入栏样式卡片扩展为平衡的 3×2 网格，第 6 格提供“当前实景预览”沙盒（融合所选形态、边框开关、多账号后缀与告警态预览），彻底消除右下角空洞。
- [x] **3.2 统一品牌视觉与输入模态三态区分**：
  - 以手绘围棋子 `GoRowIcon` 作为控制台页头与关于页统一品牌徽章；
  - 统一全插件字体抗锯齿策略；
  - 模型「输入模态」视觉区分“支持且可转发（文本/图像）”、“上游支持但插件暂不转发（PDF/音频/视频，带明确标识）”与“不支持（虚线置灰）”。
- [x] **3.3 收敛问号噪音与因果禁用态**：
  - 精简高频基础项的 `?` 视觉噪音，将关键说明以柔和副文案直出；
  - 当 `额度显示` 设为 `关闭` 时，对输入栏样式与边框控件施加降饱和禁用/弱化态及提示语，呈现清晰因果关系。

### 维度 4：信息架构与心智一致性（Information Architecture & Mental Model）
- [x] **4.1 概览页去重瘦身与冷启动引导**：
  - 合并重复的「账号概览」卡片信息（将回退链整合至「当前账号」卡片），在「当前账号」头支持直接切号；
  - 移除「服务状态」卡与页头重复的绿色状态胶囊，精简与顶部 Tab 重叠的冗余导航；
  - 针对 0 账号场景提供 3 步冷启动引导卡与直达添加按钮。
- [x] **4.2 统一术语、标题层级、外观分组与时区规范**：
  - 修正 `UsagePage` 双 `<h1>` 无障碍问题（页面模式降级为 `<h2>`），统一「用量金额」术语；
  - 重组「外观」页为三大分组：**全局界面主题 / 对话输入栏 / 侧边栏与模型选择器**；
  - 额度重置时间在历史看板 Tooltip 中同时清晰标注本地时间与 UTC 参考，消除跨 Tab 时差迷惑；
  - 设置页模型 Tab 的错误红/黄点与「已自定义」蓝点拆分语义与提示文案。
- [x] **4.3 明确侧栏额度卡“预览态 vs 生效态”边界**：
  - 侧栏卡片账号徽章增加可切换视觉提示；当预览非当前主账号时显式展示 `预览` 徽标与一键「切为当前」微按钮，并补充手动刷新图标按钮。

### 维度 5：数据可视化与决策洞察（Data Visualization & Insights）
- [x] **5.1 每日趋势图支持“用量金额”与交互式图例过滤**：
  - 趋势图模式从 2 项扩展为 3 项：`Token 构成` / `请求数` / `用量金额`；
  - Token 构成图例支持点击隐藏/显示任意序列（如一键屏蔽「缓存读」），Y 轴实时重算缩放，让输入/输出趋势清晰可见。
- [x] **5.2 模型明细表增强与分布排行联动**：
  - 明细表新增 **「缓存命中率」** 列；
  - 首列使用 `position: sticky; inset-inline-start: 0` + 语义化 `<th scope="col">` / `<th scope="row">` + 横向滚动阴影提示，防止右侧「用量金额」「占比」列被静默裁切；
  - 点击「模型用量分布」任一行高亮联动定位下方明细表对应行；CSV 导出成功后给出短暂确认反馈。
- [x] **5.3 概览 7 日图交互化与双环图例增强**：
  - 概览 7 日柱图升级为可键盘聚焦的交互柱，支持悬停/聚焦/点击查看当日 Tokens、请求数与用量金额，0 值以基线点明确区分；
  - 为 `concentric` / `rings` 胶囊及外观预览提供清晰的 `5小时 / 每周` 对应关系提示。

### 维度 6：无障碍、微交互与前端工程体验（Accessibility, Micro-interactions & Performance）
- [x] **6.1 修复全部 P0 实锤 Bug 与文档卫生**：
  - 修复 `ModelsSettings` / `ModelsPage` 在 `models.status === 'idle'` 时不触发 `loadModels()` 导致的永久假加载；
  - 修复 `OverviewPage` 点击「刷新额度」只更新时间戳不更新局部 `quota` 进度条的 Bug；
  - 修复 `AboutPage` `.rowValueMono` 遗漏 `.rowValue` 基础样式导致 `<dd>` 偏移的 CSS Bug；
  - 修复 `AccountsCard` 添加账号表单双 `autoFocus` 导致焦点错落到 Key 输入框的 Bug；
  - 修复 `UsagePill` 外部点击 `mousedown` 调用 `focusTrigger()` 反向抢占聊天输入框焦点的 Bug；
  - 同步更新 `README.md` / `README.en.md` 版本号与 `.tgz` 链接，清理无用死文案。
- [x] **6.2 客户端共享状态底座与观察器收敛**：
  - `useHostScheme()` 升级为模块级单例 `SnapshotStore`（全应用最多 1 个 `MutationObserver`）；
  - `settings-nav-icon.tsx` 兜底观察器去掉全局 `characterData: true`，避免流式吐字期间高频触发 DOM 查询；
  - 新增 `src/client/usage-store.ts` 客户端短缓存与并发去重，并让 `UsagePill` 复用 `sharedCatalog`。
- [x] **6.3 弹层视口防溢出与无障碍 Tooltip 升级**：
  - 为 `UsagePill` 弹层增加基于 CSS Anchor Positioning 渐进增强 + JS 视口碰撞偏移修正的防裁切机制；
  - 将模型列表倍率徽标等多行关键信息从原生 `title` 升级为宿主 `<Tooltip>`，提升键盘与触屏可访问性。

## 四、验收标准（v0.5.0）

1. `npm run typecheck` 通过（Host & Client 零类型错误）。
2. `npm run check:hygiene` 通过（UTF-8 无 BOM、LF、无尾随空格、CSS 规范零违规）。
3. 全部客户端与业务逻辑 Vitest 套件（含 WCAG 1.4.11 对比度测试、容器查询测试、新增回归测试）通过。
4. `npm run compile` + `npm run pack:release` + `npm run check:pack` + `npm run verify:installed` 全部通过，根目录产出唯一最新归档 `dsh-opencode-go-0.5.0.tgz`。
