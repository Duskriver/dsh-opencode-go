# 用量统计说明

[返回 README](../README.md) · [English](usage-analytics.en.md)

本页说明 `dsh-opencode-go` 用量看板统计什么、如何计价，以及哪些数据不会被计入。

## 入口

- 胶囊展开面板底部的「用量统计」行，样式与上方的账号行一致；
- 设置页的「用量统计」卡片：与「可用模型」「高级设置」同一种折叠卡片，点击展开后分两栏——第一栏「看板」打开看板，第二栏「主题」切换风格。折叠时右侧显示当前风格名。

## 数据来源

看板由 Host 侧读取 DSH 的 `ctx.sessionQuery`：

- `listSessions()` 获取会话列表（最新优先）；
- `readSession(id)` 读取完整事件日志，包含已关闭会话；
- 只扫描事件，不解析磁盘上的压缩日志，也不把会话加载为实时。

浏览器只收到聚合后的数字，不包含会话 ID、标题、正文、工作目录或任何密钥。

## 统计口径

### 计入的请求

- `dsh-opencode-go` 路由下的 `assistant/message`（每次已结算的模型请求）；
- 同一路由下的 `compaction/summary`（上下文压缩的摘要请求）；
- `opencode-go` 旧路由，仅限 0.1.16 改名（2026-09-30 UTC）之前的请求；之后的 `opencode-go` 视为 DSH 原生路由，不计入。

### 不计入

- DSH 原生 OpenCode Go 路由与其他 provider；
- fork 继承的前缀（严格低于 `inheritedEventCount` 的序号；边界槽位属于本会话，与宿主 `isOwnSeq` 的半开区间一致）；
- 未写入会话日志的模型调用（例如部分会话标题生成）；
- 无法归属到插件路由的模型调用（日志缺少路由头或模型名）——页脚以"未归属活动"单独计数，不计 token 与金额；
- 已失败的请求中网关可能已经计费、但日志里没有 usage 的调用（这类只会计入"未结算尝试"）。

### 请求时间

优先取同一 `turn:step` 的 `step/start` 时间（请求开始）；该键缺失（遗留或损坏的日志）时取本会话最近一次 `step/start`；整段会话没有任何开始事件时才退回消息事件时间，旧路由判定随请求开始时间自然修正。压缩摘要使用事件时间。区间为半开区间 `[from, to)`，按浏览器传入的 IANA 时区分桶。

### token

- 输入、输出、缓存读、缓存写分别统计；
- 计费输入 = 输入 + 缓存读 + 缓存写（pi-ai 的 input 不含缓存）；
- usage 按字段降级：存在的分量畸形只把该分量记 0，其余有效分量照常入账；仅当输入与输出同时缺失或畸形时，整条请求计入"缺用量"，不补零到金额。

### 金额

- 使用 models.dev 中 `opencode-go` 的当前价格（USD / 1M tokens）——全部历史请求都按查询时刻的价目估算（models.dev 不提供历史价）；
- 有上下文阶梯的模型，按计费输入选择最高命中的阈值；
- DeepSeek V4.1 Flash / V4 Pro 在峰时整体 ×2；
- 上游缺少价目块或价目块损坏的模型按"未计价"处理：不计金额、单独计数，费用列显示 `-`；此前这类模型被静默按 0 价计费，现在更显眼但更诚实。上游发布了合法价目（含全零）的真免费模型仍按 0 价计费；
- 价目表拉取失败或超时（至多等 4 秒）时回退到最近一次成功的价目表；完全没有任何可用价目时，出现过的模型全部列为未计价；
- 金额以整数微美元累计，页面显示为美元；这是估算，不是账单。

## 模型明细

模型行只显示模型名称，以及请求、输入、输出、缓存读、花费与花费占比；调用名与 Go / Go Plus 月限额不再出现在看板上（限额快照数据仍保留在 `src/go-plan.ts`）。

官方 `/usage` 的 5 小时 / 每周 / 每月百分比仍是额度权威值；看板不根据金额反推百分比。额度栏只显示窗口名称、百分比、进度、重置时间与临近上限的阈值刻线，不再重复"充足 / 接近上限 / 余量"等文字。

按天区域支持指针悬停：把鼠标移到日历格子上（或靠近格子 5px 以内）或折线上的任意一天，会显示该日的估算金额、请求数与 Token，同时在日历与折线上高亮同一天并画出竖向参考线。判定按"指针到最近格子的距离"计算：移到空白天或格子之间的空白处超过 5px 就立即取消选中，不会保留上一格的状态；指针离开图表区域同样清除。按模型、按天的逐日拆分不在当前契约内，悬停只呈现当日合计。

## 主题与胶囊

- 四套主题：**寂静黑**、**石墨**（默认）、**海盐青**、**暖砂**；每套都有深色与浅色版本，跟随 DSH 的明暗模式。
- 唯一的切换入口是设置页「用量统计」展开后的「主题」栏，每套风格用一张小样显示自己的表面色、强调色与文字色；偏好保存在浏览器本地（不写入设置文档）。
- 胶囊面板和看板不再提供切换，只按所选风格渲染。
- 胶囊不再带 `Go ·` 前缀；多账号时直接显示当前账号全名，名字过长时以省略号截断，完整名字保留在按钮标题与读屏标签中，展开面板仍可选择全部账号；账号切换逻辑不变。账号或连接变化引发的胶囊界面重建不再合上打开中的看板。
- 设置页保持 DSH 自己的外观，不受这套主题影响。

## 扫描上限与性能

- 默认最多扫描 **500 个会话**、**500,000 个事件**、**12 秒**，会话日志最多 8 路并发读取（宿主不支持并发时可退回串行）；
- 任一上限触发时，报告标记"不完整"并区分成因（会话数切片 / 事件预算 / 时间预算）；页脚另报"预算或上限截止时未读取的会话"数，不暗示范围已完整覆盖；
- 可点击 **扫描更多历史** 将会话上限提升到 1000 / 2000；该选择保存在浏览器本地，重新打开面板后保留；
- 已关闭会话的折叠结果在进程内按 LRU 缓存复用；live 会话的折叠结果在 5 秒内复用，过期或已关闭则重读一次；逐出只发生在每轮扫描结束后，当轮报告始终使用本轮实际读到的结果，不因缓存逐出丢数；
- 价目表在扫描开始时并行拉取，至多等 4 秒；
- 页脚分列显示列表 / 扫描 / 定价耗时；
- 同一次打开内区间终点只取打开时刻一次，重复进入同一区间不会重复扫描，**刷新**按钮强制重新扫描；
- 本次打开已看过的区间再次选中时，立即渲染上次的报告并在后台重新校验，加载期间明确标注"以下为上一轮结果"；
- 关闭弹窗会中止进行中的扫描，不后台轮询。

## 契约兼容规约

看板的查询与报告经 `src/analytics-contract.ts` 的 strict codec 双端校验，演进时遵循两条已固化的仓库规约：

- **新增字段一律走"可选数值/字符串"通道**：报告侧未知键原样放行、查询侧未知字段直接丢弃，因此两端同包发布时新增可选数值或字符串字段是安全的。本次新增的 `coverage.listMs` / `pricingMs` / `unreadSessions` / `evictedSessions` / `unattributedRequests` 均按此通道演进，旧客户端收到带新字段的报告不会拒绝；
- **禁止给枚举字段加值**：`coverage.truncation` 与模型行的 `limitNote` 是白名单校验的枚举字段，旧客户端收到未知枚举值会**整份拒绝报告**——未与旧端同发之前，禁止扩展这两个枚举。

## 已知限制

- 会话日志的 `request/header` 不含账号信息，因此历史数据无法按账号拆分；看板展示所有已保存账号的合计。
- 请求若在产生 usage 前失败/取消，可能已被网关计费，但不会产生金额。
- 压缩摘要与普通消息都按请求计入；"请求"数因此包含摘要调用。
- 设备时间或网关时钟偏差会影响峰时边界与按天分桶。
- models.dev 价格与官方套餐页可能短期不同步；页面显示价格更新时间。

## 验证

`npm test` 中的 `analytics-scan`、`analytics-pricing`、`analytics` 与两个客户端 spec 覆盖 provider 过滤、fork 截断、峰时、阶梯价、部分用量降级、请求时间回退、缓存复用窗口、截断与预算中止、并发池、未计价模型、价目回退、取消贯通、分段计时与两个入口。所有测试使用合成会话与假 query 服务，不读取真实用户日志。
