# 用量统计说明

[返回 README](../README.md) · [English](usage-analytics.en.md)

本页说明 `dsh-opencode-go` 用量看板统计什么、如何计价，以及哪些数据不会被计入。

## 数据来源

看板由 Host 侧读取 DSH 的 `ctx.sessionQuery`：

- `listSessions()` 获取会话列表（最新优先）；
- `readSession(id)` 读取完整事件日志，包含已关闭会话；
- 只扫描事件，不解析磁盘上的压缩日志，也不把会话加载为实时。

浏览器只收到聚合后的数字，不包含会话 ID、标题、正文、工作目录或任何密钥。

## 统计口径

### 计入的请求

- `dsh-opencode-go` 路由下的 `assistant/message`（每次已结算的模型请求）；
- 同一路由下的 `compaction/summary`（上下文压缩的摘要请求）；
- `opencode-go` 旧路由，仅限 0.1.16 改名（2026-09-30 UTC）之前的请求；之后的 `opencode-go` 视为 DSH 原生路由，不计入。

### 不计入

- DSH 原生 OpenCode Go 路由与其他 provider；
- fork 继承的前缀（按 `inheritedEventCount` 截断）；
- 未写入会话日志的模型调用（例如部分会话标题生成）；
- 已失败的请求中网关可能已经计费、但日志里没有 usage 的调用（这类只会计入"未结算尝试"）。

### 请求时间

优先取同一 `turn:step` 的 `step/start` 时间（请求开始）；缺失时退回消息事件时间。压缩摘要使用事件时间。区间为半开区间 `[from, to)`，按浏览器传入的 IANA 时区分桶。

### token

- 输入、输出、缓存读、缓存写分别统计；
- 计费输入 = 输入 + 缓存读 + 缓存写（pi-ai 的 input 不含缓存）；
- 缺少或损坏的 usage 计入"缺用量"，不补零到金额。

### 金额

- 使用 models.dev 中 `opencode-go` 的当前价格（USD / 1M tokens）；
- 有上下文阶梯的模型，按计费输入选择最高命中的阈值；
- DeepSeek V4.1 Flash / V4 Pro 在峰时整体 ×2；
- 金额以整数微美元累计，页面显示为美元；这是估算，不是账单。

## 月限额

模型行显示 Go / Go Plus 的月限额，来自 2026-10-18 的官方套餐页快照（`src/go-plan.ts`）。限时活动行取生效值并标注"限时"；免费模型显示"不限量"；表外模型或未计价模型显示"限额未知"。

官方 `/usage` 的 5 小时 / 每周 / 每月百分比仍是额度权威值；看板不根据金额反推百分比。

## 主题与胶囊

- 四套主题：**寂静黑**、**石墨**（默认）、**海盐青**、**暖砂**；每套都有深色与浅色版本，跟随 DSH 的明暗模式。
- 在胶囊展开面板或看板右上角的色点中切换；偏好保存在浏览器本地（不写入设置文档）。
- 多账号时胶囊显示当前账号首字母与额外账号数（如 `P+2`），完整账号名在按钮标题和展开面板中；账号切换逻辑不变。
- 设置页保持 DSH 自己的外观，不受这套主题影响。

## 扫描上限与性能

- 默认最多扫描 **500 个会话**、**500,000 个事件**、**12 秒**；
- 任一上限触发时，报告标记"不完整"，可点击 **扫描更多历史** 将会话上限提升到 1000 / 2000；
- 已关闭会话的事实缓存在内存中，重复打开与切换区间只重新聚合；live 会话每次重新读取；
- 不后台轮询，关闭弹窗即停止。

## 已知限制

- 会话日志的 `request/header` 不含账号信息，因此历史数据无法按账号拆分；看板展示所有已保存账号的合计。
- 请求若在产生 usage 前失败/取消，可能已被网关计费，但不会产生金额。
- 压缩摘要与普通消息都按请求计入；"请求"数因此包含摘要调用。
- 设备时间或网关时钟偏差会影响峰时边界与按天分桶。
- models.dev 价格与官方套餐页可能短期不同步；页面显示价格更新时间与限额快照日期。

## 验证

`npm test` 中的 `analytics-scan`、`analytics-pricing`、`analytics` 与两个客户端 spec 覆盖 provider 过滤、fork 截断、峰时、阶梯价、缓存、截断、不支持状态与两个入口。所有测试使用合成会话与假 query 服务，不读取真实用户日志。
