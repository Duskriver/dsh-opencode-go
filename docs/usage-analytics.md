# 用量统计说明

[返回 README](../README.md) · [English](usage-analytics.en.md)

用量看板展示所选 OpenCode Key 所属工作区的官方历史用量。数据可能包含其他客户端的调用，不能据此判断某次调用来自本插件；匿名 Free 调用的覆盖不作保证。

## 入口与账号

从对话用量胶囊展开后的看板按钮，或侧栏看板按钮打开。设置页不再提供用量统计卡片或主题选择器。

看板有独立的查看账号选择器，默认选择当前调用账号。切换查看账号只改变看板范围，不会切换后续对话使用的账号，也不会合并所有已保存账号。看板内的 5 小时、每周、每月额度窗口均跟随所选账号，百分比以官方额度接口为准。

## 官方数据来源

Host 使用所选账号的 Key 请求官方每日 CSV：

```text
https://opencode.ai/console/api/v2/usage/export?range=7d|30d|90d
```

一份报告的总计、每日图表与模型明细都从同一个 CSV 快照生成，避免多个接口在不同时间返回数据造成差异。支持今日、7 天、30 天、90 天；「今日」从 7 天 CSV 中筛选 UTC 当日。日期统一按 UTC，区间内缺少记录的日期补零，保持日序列连续。官方每日汇总可能延迟，刷新不保证立即看到刚结束的调用。

Key 由 Host 保存并使用。常规报告只向浏览器传递聚合数字，以及 provider、model、day 等分组字段，不含会话正文、成员字段或 Key。用户主动下载官方 CSV 时，文件可包含官方导出的成员字段。

只有官方模型网关配置支持历史查询，Host 才会将 Key 发给 `opencode.ai` Console。第三方网关配置显示不支持，不会把其 Key 发送到 Console。查询沿用已配置的代理路径，并保留取消、超时和响应体大小限制。

## 统计口径

| 项目 | 口径 |
| --- | --- |
| 请求数 | 汇总 CSV 的官方请求数 |
| 输入 / 输出 Token | 分别汇总官方输入、输出字段 |
| 缓存读 Token | 汇总官方 cache-read 字段 |
| 缓存写 Token | 合计官方 5 分钟与 1 小时 cache-write 字段 |
| 总 Token | 输入 + 输出 + 缓存读 + 两类缓存写 |
| 官方用量金额 | 精确累加 `cost_micro_cents`；`1 USD = 100,000,000 cost_micro_cents` |
| 模型分组 | 使用 provider + model；不同 provider 的同名模型分别统计 |

金额直接来自官方记录，称为「官方用量金额」，不等同于 Go 套餐之外的额外扣款。看板不使用当前模型价目表重算历史费用，也不根据金额反推订阅额度百分比。

只有来源能够支持的数据才会显示。看板不提供本地会话覆盖、摘要调用、未结算尝试或未归属活动等指标，也不会用零值代替这些未知数据。UTC 补零仅表示官方 CSV 在该日没有记录。

## 展示与刷新

- 看板在宽屏使用弹窗，窄屏使用全屏；提供 Token 堆叠日柱图或请求日柱图、模型排行与明细。
- 设置页、胶囊、展开侧栏和看板统一使用暖纸色 / 炭灰色与陶土色强调，跟随宿主明暗模式；不提供主题选择器。优先匹配本地 Anthropic Serif / Sans / Mono 字体，中文标题使用宋体等衬线回退。设置页中的宿主控件仅在插件区域内应用这套配色。
- 历史只在打开看板、切换查看账号、切换区间或手动刷新时查询，不后台轮询。关闭看板会取消正在进行的查询。
- Host 对官方报告与 CSV 使用 30 秒短缓存，按凭证、账号、网络配置、区间与 UTC 日期隔离；手动强制刷新绕过缓存。
- 鉴权、权限、网络或数据格式错误明确显示失败，不回退到本地会话扫描，也不显示伪造的零用量。

额度胶囊原有的额度刷新与历史查询相互独立。

## 验证

2026-11-06 的既有手工检查中，当前桌面 Key 在不携带 Cookie 或组织请求头的情况下可访问四个官方 Console 历史接口，均返回 HTTP 200；30 天汇总一致为 **7,064 次请求、1,105,009,939 Token、3,152,640,453 cost_micro_cents**。该检查确认每日 CSV 可提供看板所需数据，不代表所有账号均有相同权限或匿名 Free 历史一定完整。

本轮实现的自动测试、构建和界面验证结果见[验证记录](verification.md)；尚未完成的项目单独标记。
